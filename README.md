# xhs-master-site

这是一个统一的小红书账号运营控制台，采用「Prompt + Command only」模式。系统不再按“餐厅版/徒步版”拆项目，而是按真实客户业态切换策略、图片规则、正文 Prompt、一周计划和风险边界。

## 账号类型

当前内置面向潜在客户的账号类型：

- 文旅目的地 / 景区街区
- 民俗 / 非遗 / 传统文化体验
- 民宿 / 酒店 / 露营地
- 餐饮 / 在地美食
- 户外路线 / 徒步骑行活动
- 博物馆 / 展览 / 研学
- 地域特产 / 文创伴手礼
- 本地生活 / 服务门店

## 核心逻辑

- 一个网站维护多个账号。
- 每个账号选择一个 `accountType`。
- 每种账号类型绑定自己的栏目、周计划比例、图片规则、标题规则、封面规则、互动规则、商业化路径和风险禁区。
- 文旅账号优先使用真实目的地图、活动现场、导览图和票务/交通截图。
- 民俗/非遗账号优先使用真实工艺细节、作品、活动现场、授权人物图和体验流程。
- 住宿账号优先使用真实房型、空间、窗景、设施、周边体验和价格政策图。
- 餐饮账号优先使用真实菜品图、环境图、菜单图和交通节点图做 image2 图改图。餐厅图片应先存到龙虾所在电脑可访问的文件夹，文件名尽量直接使用菜品名、环境名或交通节点名，例如 `清蒸鲈鱼.jpg`、`包间.jpg`、`停车场入口.jpg`。
- 户外账号优先使用真实现场图、路线图、轨迹截图和路况图做 image2 图改图。
- 展馆研学账号优先使用真实展品授权图、展厅图、导览图、展期和票务信息。
- 产品/文创账号优先使用真实产品、包装、产地、工艺和规格价格图。
- 本地服务账号优先使用真实空间、流程、设备、资质和授权案例图。
- 所有真实发布、评论、点赞、收藏、私信都不在网站内直接执行，只生成 Prompt 和命令建议。

## 功能范围

- 创建账号并选择账号类型
- 生成账号策划案和 `profiles/<账号名>/AGENTS.md`
- 管理 `assets/<账号名>/` 素材库
- 批量登记本机可访问的素材文件夹，供龙虾直接读取
- 生成素材 `manifest.md`
- 生成一周 `note_tasks`
- 按账号类型生成正文 Prompt
- 按账号类型生成逐张 image2 图片 Prompt
- 生成给 `xiaohongshu_auto_op` 的命令建议
- 保存草稿结果
- 生成周报复盘 Prompt

## 快速开始

```bash
cp .env.example .env
npm install
npm run dev -- --port 3000
```

后端环境切换：

- 本地：`npm run env:local`
- 测试：`npm run env:test`
- 正式：`npm run env:prod`
- 构建对应环境：
  `npm run build:local`
  `npm run build:test`
  `npm run build:prod`
- 静态站点构建对应环境：
  `npm run build:sites:local`
  `npm run build:sites:test`
  `npm run build:sites:prod`
- 开发对应环境：
  `npm run dev:local`
  `npm run dev:test`
  `npm run dev:prod`

默认映射：

- `local` → `http://localhost:13010`
- `test` → `http://xhsapitest.powermatrix.tech`
- `prod` → `https://xhsapi.powermatrix.tech`

环境切换脚本会写入 `.env.local`，代码会自动补全 `/client`，不用手动再写 `/client`。

打开：

```text
http://localhost:3000
```

## 内容目录

- 账号配置：`profiles/<账号名>/AGENTS.md`
- 素材目录：`assets/<账号名>/`
- 素材 manifest：`assets/<账号名>/manifest.md`

`.env`、`.next`、`node_modules` 默认不提交。

## 素材上传流程

客户一次性提供大量图片时：

1. 少量或中等数量图片：在「素材库」直接批量上传，文件会保存到账号 `assets/<账号名>/` 目录。
2. 大型素材包或共享盘素材：先把图片同步、拷贝或挂载到运行本网站的电脑，再在「素材库」登记本机可访问的文件夹路径。
3. 点击「生成 manifest」后，系统会汇总网页上传素材和文件夹登记素材。
4. 在「图片创作」生成 Prompt 时，命令会带上 `--assets-dir`，让龙虾直接读取素材目录做图改图。

餐饮账号建议形成固定图集惯例：

1. 前 2-3 张：当天主推菜、菜品细节、套餐或活动权益。
2. 中间 1-2 张：餐厅内部环境、包间、大厅或门头。
3. 最后 1 张：交通指南漫画/信息卡，基于真实停车、路口、地标和到店路径。

## 安全原则

- 不直接执行真实发布
- 不直接执行评论、回复、点赞、收藏、私信
- 所有真实账号动作必须人工确认
- 不伪造探店、亲历、活动现场、传承人、房型、轨迹、顾客反馈、素材授权或交易结果
- AI 图生图必须基于真实素材，不得凭空伪造不存在的菜品、门店、路线、风景、民俗活动、文旅目的地、展品、产品或服务案例
